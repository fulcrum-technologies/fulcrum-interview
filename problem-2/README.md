# 문제 2 — AI 채팅 편집 기능 설계

판매자가 상품 상세페이지를 만드는 웹 편집기를 운영하고 있습니다. 사용자는 여러 페이지에 배치된 텍스트와 이미지를 직접 수정할 수 있습니다.

여기에 **채팅으로 편집하는 기능**을 추가하려고 합니다. 예를 들어 사용자가 상품 사진을 선택하고 “이 사진 배경을 흰색으로 바꿔줘”라고 입력하면, 편집된 사진이 해당 위치에 반영되는 기능입니다.

기존 편집기는 이미 동작하고 있으며, 이미지 편집이 가능한 외부 AI 서비스를 사용할 수 있습니다. 작은 개발팀이 이 기능의 첫 버전을 만든다고 가정해 주세요.

**이 기능을 어떤 구조로 설계하시겠어요?**

필요한 조건은 면접관에게 질문하거나 가정을 정해 주세요. 설계를 그림으로 설명하고, 중요한 선택을 한 이유도 함께 말씀해 주세요.

약 30분 동안 대화하며 설계를 발전시킵니다. 코드 구현은 필요하지 않습니다.
